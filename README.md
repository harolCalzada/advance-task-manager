Prueba práctica Flutter
Apex Global Mobility

---

Objetivo:
Evaluar la capacidad de desarrollar una pequeña aplicación con arquitectura limpia,
manejo de estado, consumo de APIs, manejo de dependencias, testing básico y buenas
prácticas de Flutter.
Enunciado:
Aplicación: “Gestor de Tareas Avanzado”
Requerimientos:
• Pantalla de listado de tareas con:
o Marcar como completada.
o Filtrar tareas completadas / pendientes.
• Pantalla de detalle de tarea.
• Crear / editar tarea.
• Persistencia local (sqflite o hive).
• Consumo de API REST:
o Usar jsonplaceholder.typicode.co... para traer tareas iniciales.
• Consumo de API GraphQL:
o Usar una API pública (ejemplo: countries.trevorblades.com/) y
mostrar una lista de países en una segunda pantalla.
o Usar librería recomendada: graphql_flutter o artemis.
• Arquitectura recomendada:
o Clean Architecture (presentación, dominio, datos).
o Manejo de estado: Riverpod .
o Uso de Freezed para modelos inmutables.
• Testing:
o 1 test unitario de lógica de negocio.
o 1 test widget para validar UI.
Puntos a evaluar:
• Organización del proyecto (arquitectura limpia).
• Buenas prácticas de codificación (Clean Code, SOLID).
• Manejo de estado y separación de capas.
• Consumo eficiente de APIs REST y GraphQL.
• Manejo de errores y estados de carga.
• Uso correcto de dependencias (http, dio, graphql_flutter, etc.).
• Documentación básica (README con instrucciones).
